# Remaining ESP32 support tasks

Active implementation goal from 2026-10-14: complete every task below, including its stated verification. Root execution task: T166 in todo.md. All unfinished requirements remain in scope.

Original ESP32 already has physically verified Wi-Fi passive scanning, BLE scanning/advertising, UART TX, timers and interrupts. Many expanded peripheral adapters target ESP32-S3 and have emulator or register-model evidence only. Keep implementation and physical verification separate.

Radio umbrella tasks T96 (S3) and T106 (original ESP32) remain in [todo.md](todo.md). Detailed backlog rows use unique IDs continuing that list. Mark a row complete only after integration and the stated verification.
