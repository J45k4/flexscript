# Portable binary64 words

`lib/f64.flex` implements IEEE 754 binary64 numerical operations using integer
Flexscript. Inputs and outputs are the 64-bit floating-point bit patterns in
ordinary signed words. It builds with the existing integer compiler; it needs
no FFI, host math, floating-point instruction support, Rust or executable helper
pages at runtime. This preserves the static bootstrap core and compiler-as-Wasm
execution routes.

The public numerical functions are `f64_add`, `f64_sub`, `f64_mul`, `f64_div`,
`f64_sqrt`, `f64_eq`, `f64_ne`, `f64_lt`, `f64_le`, `f64_gt`, `f64_ge`,
`f64_from_i64`, `f64_to_i64_trunc`, `f64_to_i64_nearest` and
`f64_to_i64_round`. Classification helpers inspect bits directly. The remaining
packing, shifting and mantissa helpers are implementation details.

Arithmetic rounds to nearest, ties to even, after each operation. It preserves
signed zeros, gradual subnormals and infinities. Every NaN result becomes the
positive quiet NaN `0x7ff8000000000000`; NaN payload propagation is deliberately
not part of the contract. Equality and ordered comparisons return false with
NaN, while inequality returns true. Positive and negative zero compare equal.
Division follows floating-point infinity/NaN semantics rather than integer
zero-division traps. Square root preserves negative zero and rejects other
negative inputs with canonical NaN.

Integer conversions saturate to the signed i64 bounds, with NaN becoming zero.
`trunc` drops fractions, `nearest` rounds ties to even, and `round` rounds ties
away from zero, matching Rust's `round()` followed by a saturating cast. These
functions do not reinterpret the source word as an integer value.

Addition aligns significands with guard/round/sticky bits. Multiplication forms
the 106-bit significand product from 26-bit limbs. Division produces 56 quotient
bits through bounded remainder steps. Square root consumes the 112-bit radicand
two bits at a time, without storing a 128-bit word. The loops are bounded; every
intermediate fits a signed i64 word. No operation combines multiply and add into
one rounding step.

The independent committed oracle records 64,498 exact bit-pattern results:
3,072 deterministic random pairs, 729 pairs drawn from exceptional boundaries,
586 halfway rounding pairs and integer conversion boundaries. Its optional
Rust generator canonicalizes NaNs before comparison. Native, restricted
interpreter, restricted JIT and real Wasm execute the same fixture assertions.
The corpus is differential evidence, not an exhaustive proof over all input
bit patterns. The additional math helpers below use this arithmetic library.

From the compiler repository:

```sh
build/flex-fir3 scripts/test-f64.flex -o /tmp/test-f64
/tmp/test-f64 build/flex-fir3 --report /tmp/test-f64-report.json
```

The driver uses committed words and needs no Rust. To reproduce the oracle
with a Rust compiler installed:

```sh
bun scripts/f64-goldens.js --check
```

Fixture provenance and the byte checksum live in
`tests/tooling/f64-goldens.json`. The optional generator and Rust source are
hashed independently of the numerical implementation. The generated Seta
translation in Setaworld is maintained by `seta/float64-content.js`, preserving
the same function bodies with typed signatures, bounded `for` loops and Boolean
return adapters. Compiler IR intrinsics and ordinary float syntax remain a
separate integration step; this library itself uses the integer word ABI.

`lib/f64-math.flex` adds portable word functions `f64_hypot`, `f64_atan`,
`f64_atan2`, `f64_exp`, `f64_scalbn`, `f64_sin` and `f64_cos`. The implementation
preserves the operation order of rust-lang/libm 0.2.16; attribution and license
notices are in `lib/f64-math.LICENSE`. Its differential corpus records 82,506
exact original result bits, including subnormals, signed zero, infinities and
explicit original NaN payload behavior. IEEE exception flags are not exposed
through the integer word ABI.

Sin/cos finite arguments require `f64_trig_supported(bits)` to return 1:
the absolute high word must be below `0x413921fb`, approximately 1.647 million
radians. Nonfinite result bits are covered separately. Huge finite arguments
are an explicit unsupported range; 5,884 original results are retained in
`tests/tooling/f64-math-large.words` for full reduction work.

The ordinary driver consumes committed fixtures without Rust:

```sh
build/stage2 scripts/test-f64-math.flex -o /tmp/test-f64-math
/tmp/test-f64-math build/stage2 --report /tmp/test-f64-math-report.json
```

To regenerate the independent original oracle, set `LIBM_SOURCE` to an unchanged
libm 0.2.16 checkout and run `bun scripts/f64-math-goldens.js --check`. This optional
step needs Cargo and Rust; runtime helpers and ordinary tests do not.
