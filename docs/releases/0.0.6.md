Flexscript 0.0.6 expands the self-hosted compiler with WebAssembly, SetaScript
shaders, native GUI libraries and experimental GPU execution.

- Use `flexscript` as the public command, avoiding a collision with the unrelated
  `flex` lexer generator. Release asset names remain `flexscript-<version>-linux-x86_64`.
- Compile Flexscript and SetaScript to WebAssembly, including a self-hosted
  WebAssembly compiler, persistent state, checked indexed tables and buffered
  word I/O for larger applications.
- Write typed vertex, fragment and compute shaders in SetaScript and emit GLSL
  for desktop OpenGL, GLSL ES for WebGL2, or WGSL for WebGPU. Shader modules
  support structs, portable uniform layouts, textures, depth textures and
  comparison sampling. Portable water materials provide a shared example.
- Build native applications with the reusable `libs/gui` window, canvas and
  OpenGL libraries, and terminal applications with the reusable TUI libraries.
- Extend the compiler with source frontends and bounded program transformations,
  including automatic differentiation, ML tensor operations and Pup graphs.
- Use portable binary64 arithmetic and mathematical helpers across native,
  WebAssembly, interpreted and JIT execution.
- Explore GPU compilation through PTX, direct NVIDIA Turing SASS, HIP and AMD
  RDNA targets, with Qwen inference, GPU kernels and a chat TUI. GPU backends
  and the resident GPU OS remain experimental and require compatible hardware.
- Explore freestanding x86-64 output, a software x86 emulator, KVM execution
  and Linux boot tooling. Hardware KVM requires access to `/dev/kvm`.
- Includes VM startup, allocation-accounting and emulated MXCSR test fixes.

The release provides the full Linux x86-64 compiler and a standalone static
bootstrap core. The full compiler requires the glibc loader and libc. Signed
HTTPS upgrades also require OpenSSL 3 and trusted CA certificates:

```sh
flexscript upgrade --check
flexscript upgrade
```

An installation still named `flex` can use `flex upgrade`; adopt `flexscript`
for subsequent commands without replacing the system lexer generator.

Checksums remain signed with the pinned Ed25519 release key and bound to the
release version, target and both compiler assets. The original 0.0.1 compiler
remains the independent bootstrap seed. Packaging requires a clean committed
source tree, matching verification reports and byte-identical stage 2 and 3
compilers.
