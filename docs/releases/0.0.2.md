Flexscript 0.0.2 adds local imports and native application examples.

- Local `import "path.flex";` declarations, resolved relative to the importing file.
- Nested imports and shared function/global names across source files.
- Each source file loaded once, including repeated imports and diamond dependencies.
- Errors for circular imports and duplicate declarations, with original-file diagnostics.
- Protection against overwriting any imported source file.
- Examples: custom-drawn desktop Todo, terminal Tetris, a Hello-world HTTP server, and nested imports.
- Automated native compiler builds and tag-driven GitHub releases.

Target: Linux x86-64. Output is native machine code in a standalone ELF
executable. There is no runtime Rust, libc, assembler, linker, or interpreter
dependency. Imports are resolved at compile time into one executable.

The original 0.0.1 release remains the bootstrap point. Its binary builds this
0.0.2 compiler, which then rebuilds itself. The Rust seed remains frozen at
0.0.1; the new compiler source still uses the original core syntax.

Import syntax and limits: [docs/imports.md](https://github.com/J45k4/flexscript/blob/0.0.2/docs/imports.md).
