Flexscript 0.0.3 adds C FFI, TCP networking, OpenSSL HTTPS and compiler upgrades.

- Shared-library loading and symbol lookup through `ffi_open` and `ffi_symbol`.
- Native C ABI calls with up to six integer or pointer arguments, including
  signed and unsigned C `int` returns.
- Reusable TCP client/server networking in Flexscript using Linux socket
  syscalls and the system hostname resolver.
- OpenSSL 3 TLS with certificate-chain and hostname verification, SNI and
  TLS 1.2 or newer.
- HTTPS downloads with bounded responses, chunked framing and HTTPS redirects.
- `flex upgrade --check` and `flex upgrade`, using native HTTPS without curl.
- SHA-256 verification, native ELF and version checks, atomic installation,
  permission preservation, concurrent-upgrade locking and interruption cleanup.
- Examples demonstrating C FFI and an HTTPS client.
- HTTP server responses close gracefully after rejecting oversized requests,
  avoiding truncated error replies caused by unread request bytes.

Target: Linux x86-64. Flexscript emits machine code and ELF linking metadata
directly, without invoking an assembler, C compiler or linker. Programs without
FFI remain standalone. The full compiler requires the glibc loader and libc;
HTTPS upgrades additionally require OpenSSL 3 (`libssl.so.3`) and CA certificates.

Both the full compiler and a standalone static core are provided. The original
0.0.1 binary builds the static core, which builds the full compiler. The full
compiler rebuilds itself byte-for-byte. The static core also rebuilds itself
inside an empty filesystem without a toolchain, libc or network. The Rust seed
remains frozen at 0.0.1.

The static core can compile programs using FFI and build the full compiler, but
cannot execute foreign calls or perform HTTPS upgrades itself. The initial FFI
supports integer/pointer calls; floating point, variadic calls, callbacks and
structures passed by value are outside this release.

The published 0.0.2 compiler does not have an upgrade command. Install 0.0.3 once,
then use `flex upgrade` for subsequent releases.
