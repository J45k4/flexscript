Flexscript 0.0.5 provides the next signed release for testing upgrades from 0.0.4.

- Uses the same pinned Ed25519 release key introduced in 0.0.4.
- Publishes signed checksums bound to version 0.0.5, the Linux x86-64 target,
  both compiler asset names and their SHA-256 digests.
- The 0.0.4 updater verifies `SHA256SUMS.sig` before fetching or executing the
  new compiler, checks its hash and version, and installs it atomically.
- Preserves signature enforcement, native HTTPS, permission and ownership
  preservation, concurrent-upgrade locking and interruption cleanup.

Run `flex upgrade --check` followed by `flex upgrade` from 0.0.4 to test the
signature-enforced upgrade. The full compiler requires the Linux x86-64 glibc
loader and libc. Upgrades also require OpenSSL 3 (`libssl.so.3`, `libcrypto.so.3`)
and trusted CA certificates; no curl or OpenSSL command-line tool is needed.

Both the full compiler and standalone core are provided. The original 0.0.1
compiler bootstraps this release, and the full compiler rebuilds itself
byte-for-byte. The static core can build the full compiler but cannot perform
HTTPS upgrades or execute foreign calls itself. The Rust seed remains 0.0.1.

[upgrades](https://github.com/J45k4/flexscript/blob/0.0.5/docs/upgrade.md), and
