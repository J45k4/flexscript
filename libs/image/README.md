# Images

`import "image";` provides owned RGBA8 images, EXIF orientation, alpha-correct
area/linear resizing, PNG/JPEG output and bounded JPEG previews. Collie's desktop
service and SDL renderer use this library instead of GDK Pixbuf.

The implementation and pixel operations are Flexscript. PNG, JPEG and WebP
compression/decompression still use **libpng16**, **libturbojpeg** and **libwebp**
through direct FFI adapters. Animated WebP additionally uses **libwebpdemux** and
returns its first composited canvas frame. These codecs are not reimplementations
in Flexscript. No Python, Pillow, GObject, GDK, external image process, C shim or
assembler is required to build or run the library.

Initial support is Linux x86-64 with the native compiler (IR and direct pipelines).
The private SysV codec-call adapter is generated by Flexscript into a page that
changes from writable to executable. Resizing and RGB expansion use optional
SSE4.1/SSSE3 kernels after CPUID checks; scalar pixel operations remain available.
Contexts are mutable and must not be shared concurrently between threads.

## Ownership and API

```flex
import "image";
fn normalize(bytes, length) {
    let context=image_context();
    if !context {return 0;}
    let jpeg=image_preview(context,bytes,length,1536,524288);
    // jpeg is an independently owned blob. The caller must release it.
    image_context_free(context);
    return jpeg;
}
```

Functions returning an image or blob return `0` on failure. After failure,
`image_error(context)` returns a borrowed diagnostic string. Release every image
with `image_free`, every blob with `image_blob_free`, and the context with
`image_context_free`. Operations never consume their input image or encoded bytes.
Dimensions, strides and encoded lengths are byte counts or integer pixels.

| Function | Result |
| --- | --- |
| `image_context()`, `image_context_free(c)` | Allocate/release codec handles, scratch and private native code. |
| `image_create(c,w,h,alpha)` | Zeroed, contiguous RGBA8 image. Fill all channels, including alpha; opaque images require alpha 255. |
| `image_width(i)`, `image_height(i)`, `image_stride(i)` | Dimensions and byte stride. |
| `image_pixels(i)`, `image_has_alpha(i)` | Borrowed pixel pointer and declared alpha flag. |
| `image_clone(c,i)` | Independent owned copy. |
| `image_decode(c,bytes,n)` | PNG, baseline/progressive/grayscale/CMYK JPEG, or WebP. Does not apply EXIF orientation. |
| `image_orientation(bytes,n)` | Bounded PNG/JPEG/WebP EXIF orientation, 1 if missing/invalid. |
| `image_orient(c,i,orientation)` | Owned result for one of the eight EXIF transforms. |
| `image_resize(c,i,w,h)` | Area reduction and center-aligned linear enlargement. |
| `image_fit(c,i,side)` | Preserve aspect ratio; shrink to longest side, or clone. |
| `image_encode_png(c,i)` | Owned lossless PNG blob. |
| `image_encode_jpeg(c,i,quality)` | Owned JPEG blob, quality 1–100, 4:2:0, accurate DCT. Ignores alpha, retaining RGB. |
| `image_preview(c,bytes,n,side,limit)` | Decode, orient, fit, then try JPEG quality 85/70/50 until within the byte limit. |
| `image_blob_data(b)`, `image_blob_size(b)` | Borrowed encoded bytes and actual length. |
| `image_blob_width(b)`, `image_blob_height(b)`, `image_blob_quality(b)` | Output dimensions and JPEG quality (zero for PNG). |
| `image_acceleration(c,enabled)` | `0` forces scalar, `1` enables available kernels, `-1` queries. Returns whether acceleration is enabled. |

Filtering uses premultiplied alpha internally and returns straight-alpha RGBA.
Q16 weights sum exactly to 65536. Scalar and accelerated paths produce identical
pixels. Both axes are planned once; a rolling cache retains only required rows.
Pixels with zero resulting alpha have zero RGB. JPEG output drops alpha in the
same way Collie's previous preview path did; use PNG to retain transparency.

## Bounds and supported formats

Input and encoded output are limited to 64 MiB; decoded images to 40 megapixels.
Dimensions are checked before full pixel allocation. Resize workspace is capped
at 256 MiB, independently of input/output image allocations. Fit limits are
1–16384 pixels. A preview fails if none of its three quality levels fits the
requested byte limit. Context memory and image buffers are explicitly released.

PNG handles palette/transparency, grayscale, RGB/RGBA, Adam7 and conversion to
8-bit sRGB samples through libpng's simplified API. JPEG CMYK follows the common
inverted Adobe convention. This initial library does not provide ICC color
management, metadata preservation, SVG, GIF or multi-frame playback. Collie's
three toolbar icons are rasterized at build time in Flexscript; editable SVG
sources remain in the repository.

On Debian/Ubuntu install `libpng16-16t64` (or the distribution's libpng16 runtime),
`libturbojpeg0` on Debian (Ubuntu 24.04 calls it
[`libturbojpeg`](https://packages.ubuntu.com/noble/libturbojpeg)), `libwebp7`
and `libwebpdemux2`. On Arch the corresponding packages
are `libpng`, `libjpeg-turbo` and `libwebp`.

## Verification and performance

```sh
FLEX_COMPILER=build/collie-desktop/compiler python3 scripts/test-image.py
FLEX_COMPILER=build/collie-desktop/compiler python3 scripts/test-image.py --pipeline direct
nice -n 19 python3 scripts/benchmark-image.py
```

Tests use Pillow only as an independent oracle. They cover codec formats,
truncated/oversized input, all EXIF transforms, independent floating point filter
arithmetic and scalar/SIMD identity. Benchmarking additionally requires a C
compiler and GDK Pixbuf development files for its comparison adapter; neither
is part of this library. See [measured results](benchmark.md) and
[raw samples](benchmark-results.json) for the workload and remaining losses.
