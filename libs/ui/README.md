# Portable views

One shared `view` AST and compiled update mechanism, with native Android, DOM and
SDL desktop adapters. Desktop layout, drawing and editing are Flexscript using
the existing GUI canvas. See [the UI guide](../../docs/ui.md),
[browser counter](../../examples/ui/counter.flex),
[native counter](../../examples/ui/desktop-counter.flex), and
[Collie's live desktop permissions screen](../../examples/ui/desktop-permissions.flex).
