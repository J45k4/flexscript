# Pinned Unicode 17.0.0 inputs

These unmodified upstream Unicode Character Database files are canonical inputs
for the Flexscript grapheme/bidi/line-break generators and conformance suites.
`manifest.json` records the exact upstream URLs and SHA-256 hashes. Each data
file retains its copyright/terms notice; `LICENSE.txt` contains Unicode License
V3. The application uses generated Flexscript tables and does not load these
files at runtime. Python is used only as an independent test parser/orchestrator.
