
LINUX DESKTOP PLATFORM
hardware_capabilities() and hardware_access_info() report the actual implemented Linux adapters. Android APIs and grants never enable absent Linux adapters. Unsupported operations return device_error() with unsupported_operation. Check real capability facts first. All operations use the same typed db values and per-conversation grants as on Android. Device maps are lists of [key,value] pairs; use device_field(map,key). Blobs use db_word/db_bytes. Handles are opaque text, scoped to one conversation, invalid after closing, revocation or app restart. Do not restore OS handles from persistent state.

Network grant: net_list(), net_info("default"), net_resolve("default",host). Only selector "default" is implemented; it uses the system route without modifying it. net_tcp_connect("default",host,port,timeout_ms), net_tcp_open("default"), net_tcp_dial(handle,host,port,timeout_ms), net_tcp_listen("default",port,backlog), net_tcp_accept(listener,timeout_ms), net_udp_open("default",port), net_udp_send(handle,host,port,data), net_udp_receive(handle,limit,timeout_ms), net_http("default",https_url,timeout_ms). Ports 1..65535, bind port 0 allows the OS to choose; backlog 1..32, timeouts 1..8000ms. Data is text/blob up to32768 bytes. net_http returns status/url/body blob/truncated, HTTPS only, no model credentials or cookies, at most3 HTTPS redirects. device_read(handle,limit1..32768,timeout_ms), device_write(handle,data), device_info(handle), device_wait(handle,timeout_ms0..1000), device_close(handle). Reads/accept return db_null on timeout or EOF, writes may be partial. device_wait reports readability, not guaranteed delivery. Maximum32 resources/conversation. Ordinary host OS permissions apply.

Device status grant: battery_info() reads actual /sys/class/power_supply entries; thermal_info(forecast_seconds) reads actual thermal zones in millidegrees Celsius. Missing hardware yields empty inventories rather than fabricated readings.
Sensors grant: sensor_list() returns {sensors,total,next}, sensor_info(id) reads an enumerated IIO device's name. Sensor measurement streaming is not implemented yet.
USB grant: usb_list(offset,limit1..32) returns {devices,total,next}; next=-1 ends paging. usb_info(id) reads actual Linux sysfs metadata. USB transfer and Android USB serial RPCs are not implemented on Linux yet. Inventories are not permission or transfer proof.

User attachment/camera capture, clipboard, window input and workspace files are desktop UI services, separate from model-granted guest device access. Bluetooth/BLE, NFC/HCE, UWB, cellular, Wi-Fi Direct/Aware, secure elements, Android Keystore, biometrics, VPN routing, global accessibility, screen-capture and audio/MIDI guest adapters are not currently implemented for Linux. Never claim otherwise or fabricate readings, acknowledgements or capability success.
